# 🚀 Nexus Digital Agency

> **Get your shit done.** — A fully custom digital agency website built for real businesses that want results, not excuses.

---                   

## 📌 What Is This?

**Nexus Digital** is a multi-page agency website designed to attract and convert local small business clients. It presents services, showcases portfolio work, explains the process, and captures leads — all in one clean, fast, no-backend site.
                    
Built with pure **HTML, CSS, and JavaScript** — no frameworks, no bloat. Deploy anywhere in seconds.

## ⚠️ Problems This Solves

### ❌ Problem 1 — No Professional Web Presence
Most freelancers and small agencies have no website, so clients don't trust them.

**✅ Solution:** Nexus Digital gives you a complete, professional agency website that looks premium from day one.

---

### ❌ Problem 2 — Clients Don't Know What You Do
When you pitch local businesses, they often ask: *"What exactly do you offer? How much? What's the process?"*

**✅ Solution:** Dedicated pages — `services.html`, `pricing.html`, `how-it-works.html` — answer every question before a call even happens.

---

### ❌ Problem 3 — No Portfolio to Show
Without proof, no one hires you.

**✅ Solution:** A full `portfolio.html` page with showcase images (`portfolio-1.png` through `portfolio-6.png`) displays your past work visually and credibly.

---

### ❌ Problem 4 — Hard to Deploy
Complex setups with servers, databases, or CMS waste time for simple agency sites.

**✅ Solution:** Pure HTML/CSS/JS — just drag-and-drop to **Netlify Drop** or any static host. Zero configuration needed.

## 🛠️ How to Use / Deploy

### Option 1 — Netlify Drop (Recommended, No GitHub Needed)
1. Download/zip this entire repo
2. Go to [netlify.com/drop](https://netlify.com/drop)
3. Drag and drop the folder
4. Your site is live in 30 seconds ✅

### Option 2 — GitHub Pages
1. Fork this repo
2. Go to `Settings > Pages`
3. Set source to `main` branch, root folder
4. Done ✅

### Option 3 — Local Preview
Just open `agency-home.html` directly in your browser. No server needed.

## ✏️ How to Customize It

| What to Change | Where |
|---|---|
| Agency name, tagline | `agency-home.html` — hero section |
| Services list | `services.html` |
| Pricing packages | `pricing.html` |
| Portfolio images | Replace `portfolio-1.png` to `portfolio-6.png` |
| Contact form | `contact-agency.html` — update email/form action |
| Colors, fonts | `agency-styles.css` — top CSS variables |
